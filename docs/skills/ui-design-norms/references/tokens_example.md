# トークンの例

デザイントークンの出発点として使える値の組である。面・文字・状態色は Windows 11(WinUI)のテーマリソースと Fluent 2 をもとに、Qt や Web でそのまま使える不透明色にしてある。系列色はこの例のために選び、コントラストと色覚シミュレーションで確かめた。製品の配色、ブランド色、対象の OS に合わせて変えてよい。変えたら同じ基準で確かめ直す。

## 色の役割

| ロール | 用途 | ダーク | ライト |
|---|---|---|---|
| `bg.base` | ウィンドウの地、ナビ、ヘッダー | `#202020` | `#F3F3F3` |
| `bg.layer` | ページ本体、パネルの面 | `#272727` | `#F9F9F9` |
| `bg.card` | パネル内のグループ面 | `#2D2D2D` | `#FFFFFF` |
| `bg.sunken` | グラフ・ログの描画面 | `#1C1C1C` | `#FFFFFF` |
| `bg.control` | ボタン・入力欄の地 | `#373737` | `#FFFFFF` |
| `bg.control.hover` / `.pressed` | | `#3D3D3D` / `#323232` | `#F6F6F6` / `#F0F0F0` |
| `stroke.control` | コントロールの枠 | `#3F3F3F` | `#E0E0E0`(下辺 `#C8C8C8`) |
| `stroke.divider` | 区切り線 | `#333333` | `#E5E5E5` |
| `text.primary` | 本文、値 | `#FFFFFF` | `#1A1A1A` |
| `text.secondary` | ラベル、単位 | `#CCCCCC` | `#5C5C5C` |
| `text.tertiary` | 最小/最大、プレースホルダ、「推定」のタグ | `#969696` | `#868686` |
| `text.disabled` | 無効状態 | `#717171` | `#A0A0A0` |
| `accent` | 主ボタン、選択、フォーカス、リンク | `#60CDFF` | `#005FB8` |
| `accent.on` | 主ボタン上の文字 | `#000000` | `#FFFFFF` |
| `accent.surface` | 選択中の面 | `#1F3A4D` | `#E5F1FB` |
| `success` / `.surface` | 動作中、接続中、成功 | `#6CCB5F` / `#393D1B` | `#0F7B0F` / `#DFF6DD` |
| `caution` / `.surface` | 注意、危険が増した状態、上限に制限中 | `#FCE100` / `#433519` | `#9D5D00` / `#FFF4CE` |
| `critical` / `.surface` | 故障、エラー、通信断 | `#FF99A4` / `#442726` | `#C42B1C` / `#FDE7E9` |
| `danger.fill` / `.on` | 非常停止、破壊的操作の確定(赤の塗りはこれだけ) | `#C42B1C` / `#FFFFFF` | 同左 |
| `neutral.surface` | 平常の状態バッジの面 | `#3A3A3A` | `#E6E6E6` |
| `plot.grid` | グラフの格子 | `#2D2D2D` | `#EEEEEE` |

- ライトの caution は文字用に暗くしてある。黄色の文字は白地でコントラストが取れないためである。塗りが必要なら `#FCE100` の面に暗い文字を載せる。
- `text.tertiary` は本文の 4.5:1 に届かない場合がある(ライトで約 3.5:1)。重要な情報に使わない。
- 状態色どうし(緑と青、緑と赤)は色だけでは区別しにくい組がある。状態は必ずアイコンと文字を伴わせる。

## 系列色(グラフ・対象の識別色)

| 枠 | ダーク(`bg.sunken` `#1C1C1C` 上) | ライト(`#FFFFFF` 上) |
|---|---|---|
| 0 | `#169B73`(青緑) | `#00664F` |
| 1 | `#9D8CF0`(紫) | `#7B61E0` |
| 2 | `#F49AC0`(桃) | `#D6589A` |

- 状態色(赤・琥珀・緑)と accent の青を避けた色相から選んである。
- 複数の対象を重ねるときは、枠を対象に割り当て、指令・目標は同じ色の破線にする。対象が 1 つのときは、枠を量の役割に割り当てる(例: 実測 = 枠 0 の実線、目標 = 枠 1 の破線、上限・保護 = `caution` か `critical` の細線)。
- 確かめた値: 背景とのコントラストはダーク 4.8〜8.3:1、ライト 3.7〜7.0:1。色差 ΔE(OKLab の距離 × 100)は、通常の色覚で最小 16.6(ダーク)/ 19.3(ライト)、1 型・2 型・3 型の色覚シミュレーション(Machado 2009)で最小 11.8 / 12.4。
- 台数が多いツールでは 6〜8 色に増やし、同じ基準で確かめる。目安は、背景とのコントラスト 3:1 以上、通常の色覚で ΔE 15 以上、色覚シミュレーションで ΔE 8 以上。3:1 に届かない色を使うなら、凡例と最新値の文字ラベルを必須にする。
- 系列色の明度(OKLab の L)を近い範囲に揃える。1 色だけ明るいと、その系列だけが重要に見える。

## 状態の重ね合わせ

| 状態 | 値 |
|---|---|
| hover | 前景色 8% を重ねる |
| pressed | 前景色 12% |
| selected | accent 15〜20% の面 |
| disabled | 内容 38%、面 12% |
| focus | 2px の accent のリング(キーボード操作時だけ) |

## 文字

| ロール | サイズ / 行高(px) | 太さ | 用途 |
|---|---|---|---|
| caption | 12 / 16 | Regular | 補足、単位の補足、最小/最大、タイムスタンプ |
| body | 14 / 20 | Regular | 本文、ラベル、ボタン、入力欄 |
| body-strong | 14 / 20 | Semibold | グループ見出し、表のヘッダー |
| subtitle | 20 / 28 | Semibold | パネル・ダイアログの見出し、空状態 |
| readout-secondary | 20〜24 / 28〜32 | Semibold、等幅数字 | 副次の読み値(目標値、ほかの量) |
| readout-primary | 32〜40 / 40〜48 | Semibold か Bold、等幅数字 | 主要な実測値(画面で最も大きな文字。本文の 2 倍以上) |

- 1 画面で使うのは 4〜5 段階まで。12px 未満を使わない。
- 主要な実測値は、ほかの要素(見出し、非常停止のラベル)より大きくする。読み値の単位は値より小さく(body 程度)、secondary 色にする。
- 太さは Regular(400)と Semibold(600)だけにする。
- フォントは OS の UI フォントを使う(Windows: Segoe UI / Yu Gothic UI、macOS: SF Pro / ヒラギノ、Linux: Cantarell / Noto Sans CJK)。数値は等幅か、等幅数字を有効にしたフォントにする。
- 複数行の日本語は行高を 1.43〜1.6 倍にする。
