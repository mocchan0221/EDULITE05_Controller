作成: Opus / 2026-10-03。実行: Opus(CLI / GUI)+ ユーザー(手で触る・電源・固定)。すべての試験で、まず LOW で行う。

## 前提
- 安全修正 W(±4π 折り返し対策・多回転を mechPos で初期化)がコミットされてから MIT 系を行う
- 位置は 4π の内側に置く(現状 mechPos ≈ 12.1 rad で端に近い。最初にゼロ点設定 T0 を行う)
- 非常停止: GUI の Pause / Esc、または `python -m edulite05.cli estop --port COM7`。電源を切るのが最終手段
