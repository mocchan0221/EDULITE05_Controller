# 文書の書き方

このプロジェクトで書く日本語の文章(利用者向けの文書、`docs/research/`・`docs/design/` の資料、UI 文言、コミットメッセージ)は、すべて次の 2 つの規範に沿って書く(CLAUDE.md の統一規範)。規範の本文はリポジトリに複製しないので、URL から読む。

| 規範 | URL | 適用範囲 |
|---|---|---|
| japanese-tech-writing(日本語技術文書の文章規範) | https://gist.github.com/k16shikano/fd287c3133457c4fd8f5601d34aa817d | すべての文 |
| cognitive-rhythm-writing(認知リズムを生むための日本語ライティング規範) | https://gist.github.com/k16shikano/eb2929f13ed19c97188393d297be8432 | 説明の文章だけ(下記) |

## japanese-tech-writing をすべてに適用する

特に次の点を守る。

- 1 段落に 1 トピック。段落の最初の文で、その段落が何の話かを示す。
- 段落どうしの関係は接続表現で明示する。
- 用語は文書全体で 1 つに揃える(下の用語表)。
- 否定・限定するときは、その理由を一文添える。
- 「重要なのは〜」「〜において」「まとめると」のような中身のない言い回しを使わない。
- 翻訳調の比喩と擬人化(「運ぶ」「効く」「〜を引き受ける」など)を使わず、平易な動詞で書く。
- 説明の直後に要約を置く、同じ警告を何か所にも書く、といった重複をしない。詳しい説明は 1 か所に置き、ほかからは節番号で参照する。
- 主語をはっきりさせる(利用者が〜する、アプリが〜する、モータが〜する)。
- 概念は、種類(モード、操作、状態など)を先に示してから詳細を書く。
- 散文・表・図・コードの役割を分ける。手順は番号付きの手順、参照情報は表、理由は散文に書く。

## cognitive-rhythm-writing は説明の文章だけに適用する

適用するのは、読者に「なぜそうなっているか」を伝える文章である。

- マニュアルの冒頭
- 安全の章
- 理由の説明(位置の ±4π の折り返しと「原点に設定」、暴走ガード、電流モードの実電流が指令の約 1/9 になること、type 22 で 0x70xx が保存されないこと、limit_torque を瞬間的に超えること、mechPos による多回転位置の較正など)
- トラブルシューティングの原因の説明

手順、参照用の表、CLI のリファレンス、ショートカットの表には適用しない。これらは番号付きの手順と表のまま、目で探しやすく保つ。参照情報に緊張や語りを持ち込まない。

メタな文(「この節では〜を説明します」のような予告や進行の実況)を書かない規則だけは、すべての文書に適用する。節の頭には、読者の置かれた状況や困りごとを書く。

## マニュアルとしての形

- マニュアルは引いて使うものなので、目次を保ち、見出しは作業を指す形(「〜するには」)を自然な範囲で使う。見出しで結論を言い切らない。
- 事実を変えない。数値・挙動は `docs/research/hw_bench.md`、`docs/research/el05_protocol.md` §8.0、`profiles/el05.toml`、`docs/design/open_questions.md`、CLI の `--help` で確かめる。
- UI のラベル(ボタン名・ページ名)は `src/edulite05/app/i18n/ja.toml` と完全に一致させる。ボタンは [ボタン名] と書く。
- 太字は見出し代わりの小見出しと、誤読を防ぐ要所(1 節に 1〜2 か所)に限る。

## 用語

| 概念 | 使う語 | 使わない語・注意 |
|---|---|---|
| 指令の上限の組 | 出力段階 / 低出力 / 高出力 | 「段階」だけ、「LOW / HIGH」だけ(初出や設計文書の括弧書きは可) |
| 上限を超えた指令の扱い | 上限に制限する(UI の「制限中」と揃える) | 切り詰める、クランプ |
| 全モータを即座に止める操作 | 非常停止 | E-STOP |
| モータの出力の ON / OFF | 有効化 / 無効化 | |
| 指令の送信の開始 / 終了 | 運転開始 / 運転停止 | 「停止」だけ(無効化と紛れる) |
| 無効化されたモータの状態 | 停止中(条件として書くときは「停止中(無効)」) | 運転停止しただけの状態(有効)と混同しない |
| 指令を検査して上限に制限するしくみ | 安全制限(内部名 SafetyGuard。UI の表記はそのまま引用) | |
| ±4π で折り返す位置 / 累計の位置 | 折り返し位置 / 多回転位置 | |
| 位置 0 の設定 | ゼロ点(ボタン名は「原点に設定」、保守ページは「ゼロ点を設定」) | |
