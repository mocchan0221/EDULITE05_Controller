## 1. 製品概要

- 製品名: EDULITE 05 / EL05 — 「6N.M 準ダイレクトドライブ一体型モータモジュール」（EN 表紙 / CN 表紙）
- 構成: 3 相 PMSM + 遊星減速機 9:1 + FOC ドライバ + 磁気エンコーダ一体型
- 通信: CAN 2.0（既定は独自プロトコル・29bit 拡張フレーム・1 Mbps）。CANopen / MIT プロトコルへ切替可能（詳細は protocol 文書）
- 外形はほぼ RS05 と同一（⌀46 × 44 mm）だが、減速比・トルク・重量が異なる別モデル（§9 参照）

## 6. コネクタ・配線

### 6.1 ドライバインタフェース（EN p.12 §2.2–2.3 / CN p.9 §2.2–2.3）

基板上のパッド配置（写真）:

```
 ┌───────────────────────────────┬────────┐
 │   (VBAT+)          (GND)      │ CAN-L  │
 │    大電流ピン       大電流ピン  │ CAN-H  │
 └───────────────────────────────┴────────┘
```

| 信号 | 説明 |
|---|---|
| VBAT+ | 電源 +（15–60 VDC、定格 48 V） |
| GND | 電源 − |
| CAN-L | CAN Low |
| CAN-H | CAN High |

| 側 | 型番 | メーカ |
|---|---|---|
| 基板側 | **XT30PB(2+2)-M.G.B** | AMASS（艾迈斯） |
| ケーブル側 | **XT30(2+2)-F.G.B** | AMASS（艾迈斯） |

- XT30(2+2) は電源 2 ピン + 信号 2 ピンの一体コネクタ。
- 外形図側面に **CN1 / CN2** の 2 コネクタが描かれており（EN p.8 図）、EN p.13 に「通信ケーブルが 2 本ある」とあることから、**デイジーチェーン用に同一ピン配置のコネクタ 2 個**を持つと推定。
- **ケーブル色・ピン番号の詳細、電源と CAN の GND 共通化については記載なし。**

### 6.2 CAN 終端

- **モータ本体側の終端抵抗の有無・切替方法はマニュアルに記載なし。**
- 公式 USB-CAN モジュール: **DIP スイッチ 2 = ON で 120 Ω 終端を接続**（正常通信に必要）。**DIP スイッチ 1 = ON で Boot モード**となり上位機と接続不可（EN p.13 §3.1 / CN p.10 §3.1）。
- 推奨: バス両端で終端（電源 OFF 時に CAN-H/L 間 ≒ 60 Ω を確認）。モータ内蔵終端の有無は実機で要測定。

### 6.3 上位機接続（EN p.13 / CN p.10）

- CAN–USB ツール（公式 USB-CAN モジュール、CH340 ドライバ、既定 AT モード）経由で PC と接続。
- AT モードのシリアルフレーム: ヘッダ `41 54`（"AT"）、テール `0D 0A`。フレーム形式は protocol 文書 §1.4 を参照。
- `docs/vendor/usb_can/USB_CANHUB使用说明V1.0.pdf` は別製品（SocketCAN, `ip link ... bitrate 1000000`）の説明で、AT 形式とは異なる。

### 8.2 過負荷（熱）モデル（EN p.9–10 / CN p.6–7）

- 相電流とサーミスタ温度から各相巻線温度をリアルタイム推定し、熱しきい値到達で保護動作。
- ストール時は 3 相の発熱が不均一になり、単相発熱は回転時の **1.414 倍**。

| 6 | 5 |
| 5 | 7 |
| 4 | 14 |
| 3 | 44 |
| 2 | 300 |
| 1.8 | 定格（連続） |

**ストール時 最大過負荷**

| 負荷 (N·m) | 連続可能時間 (s) |

| 6 | 1 |

## 10. 安全上の注意（EN p.1 Precautions, p.20, p.52, p.65 / CN p.1, p.15, p.38, p.47–48）

1. 規定の動作パラメータ内で使用すること（逸脱は重大損傷の原因）。**ピークトルク超過による損傷は保証対象外**（EN p.3）。
2. **運転中に制御モードを切り替えないこと。** 切替前に必ず停止コマンド（type 4）を送る。
3. 使用前に部品の欠品・損傷を確認。
4. 分解しないこと（回復不能な故障の原因）。
5. 接続時に短絡がないこと、インタフェースを正しく接続すること。
6. トルク制限・保護温度・過温時間は変更しないこと。
7. **ダンピング（Kp=0, Kd>0）で外部から回されると発電する → 過電圧防止のため電源で吸収できるようにしておく**（EN p.52 / CN p.38）。電源は回生を吸収できるもの（またはブレーキ抵抗/バッテリ）を推奨。
8. CANopen の非常停止（Controlword = 11）は**サージ電圧の危険あり**（EN p.65 / CN p.47–48）。
9. PP モードは運転中の速度・加速度変更不可。緊急停止したい場合は運転中に `vel_max` を 0 に書き込む（EN p.54 / CN p.39）。
10. 子供に触らせない、高温高圧環境で使用しない（EN p.1）。
11. ファームウェア書換時は **CAN ボーレート 1 Mbps であること**（CN p.13 §3.3.3 見出し）。書換失敗でも内部プログラムは消えない（再投入して再実行可）。
