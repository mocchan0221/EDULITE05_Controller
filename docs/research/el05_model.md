# EL05 3D モデル(STEP → GLB)変換記録

Phase 0 タスク 0-4 の成果記録。ベンダ提供の CAD(`docs/vendor/el05/el05.stp`、Creo 出力)を、3D ビューア用の
`assets/models/el05.glb` に変換した。変換スクリプトは `tools/convert_step.py`。

## 1. 成果物

| ファイル | 内容 |
|---|---|
| `assets/models/el05.glb` | 単位 m、回転軸 = 原点を通る +Z、`rotor` / `stator` の 2 グループ。1,139,156 byte(1.14 MB)、53,526 三角形 |
| `assets/models/preview.png` | pyvista off-screen による確認画像(出力側・背面側の 2 視点。rotor=橙、stator=灰) |
| `tools/convert_step.py` | 変換スクリプト(再実行で同一バイト列の GLB が得られることを確認済み) |

入力 STEP: 2,430,955 byte、SHA-256 `3c970be58644420e97a332473e9b1d806601125c9e95c95743ddeb0c99e27ee3`(ベンダ原本。編集していない)。

## 2. 再現手順

リポジトリルートで(pyproject には依存を追加しない。一時環境で実行):

```
UV_LINK_MODE=copy uv run --no-project --with cascadio --with trimesh --with numpy python tools/convert_step.py
```

プレビュー PNG も更新する場合(`pyvista` を追加し `--preview` を付ける。off-screen 描画に失敗した場合は警告を出してスキップし、GLB は生成される):

```
UV_LINK_MODE=copy uv run --no-project --with cascadio --with trimesh --with numpy --with pyvista python tools/convert_step.py --preview
```

使用版: cascadio 0.1.1、trimesh 5.x、numpy、pyvista(プレビューのみ)。実行時間は数秒。
主なオプション: `--step` / `--out`(入出力の変更)、`--fine-screws`(ねじを粗メッシュに差し替えず残す)。
標準出力に、軸フィットの部品別結果・再読込検証(ノード別三角形数・bounds・軸位置)が出る。

変換の要点:
1. cascadio で STEP → GLB を 2 回変換する。本体は `tol_linear=0.01 mm, tol_angular=0.5 rad`、ねじ用は `tol_linear=1.0 mm, tol_angular=1.5 rad`(粗い)。
2. ノード名(`_X2_<UTF-16BE hex>_X0_`)を復号して部品を識別し、英語 ID と rotor/stator を割り当てる。
3. 同心部品の外周円から回転軸を求め(§4)、軸が原点・Z 軸になるよう平行移動する。
4. ねじ 4 本は粗メッシュに差し替える。
5. 空ノード `rotor` / `stator` の下に部品ノードをぶら下げ、部品ごとに PBR マテリアル(仮の色)を付けて GLB 出力。
6. 出力 GLB を再読込して 2 グループ・bounds・三角形数・軸位置を自動検証する。

## 3. 部品一覧と rotor / stator 分類

STEP は 11 solid、部品 15 インスタンス。Creo の日本語以外の部品名は `\X2\<UTF-16 hex>\X0\` でエンコードされ、cascadio はそれを `_X2_<hex>_X0_`(末尾の数字は OCC が付ける連番)としてノード名に残す。
エンコードされていない名前(`00_1-4459` など)は、同じ部品の別インスタンス名(Creo の自動名)。

| STEP/cascadio のノード名(元の名前) | デコード(中国語) | 意味(日本語 / English) | GLB ノード名 | グループ | 三角形数(変換直後 → 最終) |
|---|---|---|---|---|---|
| `_X2_8F9351FA8F74_X0_` | 输出轴 | 出力軸(遊星キャリア兼用の円盤状出力部) / output shaft | `output_shaft` | **rotor** | 5,012 → 5,012 |
| `_X2_8F749500_X0_`、`00_1-4459`、`00_1-4459_1` | 轴销 ×3 | ピン(遊星ピン。出力面から 3 mm 突出) / shaft pin | `pin_1`〜`pin_3` | **rotor** | 1,932 ×3 → 同 |
| `_X2_57AB7247_X0_`、`00_1-5178`、`00_1-5178_1` | 垫片 ×3 | ワッシャ(ピンまわりのシム) / washer, shim | `washer_1`〜`washer_3` | **rotor** | 424 ×3 → 同 |
| `_X2_8F74627F_X0_2`(小) | 轴承 | 中心軸受(外径 10 mm × 幅 4 mm、出力軸の中心穴内) / center bearing | `bearing_center` | **rotor** | 1,360 → 1,360 |
| `_X2_8F74627F_X0_1`(大) | 轴承 | 主軸受(外径 37 mm × 内径約 30 mm × 幅 4 mm) / main bearing | `bearing_main` | stator | 3,096 → 3,096 |
| `_X2_9F7F5708_X0_` | 齿圈 | リングギア兼出力側フランジ(外径 46 mm、取付穴あり) / ring gear | `ring_gear` | stator | 5,640 → 5,640 |
| `_X2_673A58F3_X0_` | 机壳 | ハウジング(外径 46 mm 円筒) / housing | `housing` | stator | 7,276 → 7,276 |
| `_X2_540E76D6677F_X0_1` | 后盖板 | リアカバー / rear cover plate | `rear_cover` | stator | 8,200 → 8,200 |
| `_X2_53617C27_X0_` | 卡簧 | サークリップ(主軸受の外輪止め) / circlip, retaining ring | `circlip` | stator | 1,052 → 1,052 |
| `PRT0001` | (名前なし) | 板状の部品。推定: 基板(PCB) / unnamed board-like part (presumably PCB) | `pcb` | stator | 7,518 → 7,518 |
| `LUOSI_1`、`LUOSI_1_1`(×3) | 螺丝(拼音 LUOSI) | ねじ ×4(リアカバー固定) / screw | `screw_1`〜`screw_4` | stator | 25,874 ×4 → 1,826 ×4 |
| 合計 | | | | | **149,718 → 53,526** |

- 最終の三角形数は rotor 13,440、stator 40,086(ねじ 4 本で 7,304)。ねじが占める割合は変換直後 69.1%(103,496 / 149,718)、粗メッシュ化後 13.6%。
- 番号付けについて: `pin_n` / `washer_n` / `screw_n` は軸まわりの角度(atan2)昇順。ピン 3 本は軸から 8.85 mm、角度 -90.4°、29.6°、149.6°(ほぼ 120° 間隔)。ねじは軸から 20.25 mm、角度 -143°、-53°、37°、127°(90° 間隔)。

### 分類の根拠

- **rotor = 出力軸と一緒に回る部品**: 出力軸(`output_shaft`)、ピン 3 本、ワッシャ 3 枚、中心軸受。
  - 出力軸は出力そのもの。ピンは出力軸を貫通して取り付く遊星ピン(位置から推定)で、遊星キャリア(出力軸)と共に公転する。ワッシャはピン位置(軸から同じ 8.85 mm、同じ角度)にあり、やはり軸と一緒に公転する。
  - 中心軸受は出力軸の中心穴(半径 5.0 mm)に外半径 5.0 mm で嵌まる(外径 = 穴径)ので、外輪が出力軸側。回転対称なので見た目には影響しない。
- **stator**: ハウジング・リングギア・リアカバー・サークリップ・ねじ・基板は筐体側で固定。主軸受は内輪が出力軸フランジ、外輪がリングギア内径に接する(内径 R15.0 が出力軸の R15 段、外径 R18.5 がリングギアの内周)が、1 つの solid で内外輪に分離できないため、質量の大きい外輪側に合わせて stator とした(回転対称なので視覚上の差はない)。サークリップ(R17.9〜18.9)は主軸受の外輪止めなので stator。
- 回転対称(軸まわりに同じ形)の部品は、どちらのグループに入れても回転しても見た目が変わらない。**回転が見えるのは非対称な形状を持つ出力軸の穴・ピン・ワッシャのみ**。出力軸の円盤(オレンジ)が回り、ピン 3 本が公転する。
- この CAD はモータ内部(ロータ磁石・ステータコイル・遊星歯車・太陽歯車)を含まない簡略モデル。よって「モータのロータ」でなく「出力軸側」が rotor。
- 目視確認は `preview.png` で行った(出力側にオレンジの出力円盤とピン 3 本、背面にねじ 4 本)。

## 4. 回転軸の位置

### 方法

出力軸・リングギア・主軸受・中心軸受・サークリップ・ハウジング・リアカバーの 7 部品は、いずれも回転対称(円筒面)である。各部品について、bbox 中心からの最大半径(±0.02 mm)に乗る頂点を集め、XY 平面での代数的最小二乗円フィットから中心と半径を求めた。7 部品の中心の中央値を回転軸とした。

### 結果(CAD 座標、mm)

| 部品 | 中心 x | 中心 y | 半径 R |
|---|---|---|---|
| output_shaft | -12.6324 | 3.6422 | 16.000 |
| ring_gear | -12.6324 | 3.6422 | 23.000 |
| housing | -12.6324 | 3.6422 | 23.000 |
| rear_cover | -12.6324 | 3.6422 | 22.998 |
| bearing_main | -12.6324 | 3.6422 | 18.500 |
| bearing_center | -12.6324 | 3.6422 | 5.000 |
| circlip | -12.6324 | 3.6422 | 18.900 |

- **回転軸 = Z 軸に平行、(x, y) = (-12.6324, 3.6422) mm を通る**。部品間のばらつきは 0.0001 mm 未満で、半径が 16.000 / 23.000 / 18.500 / 5.000 と丸い値になった(事前調査の (−12.6, 3.6) mm と一致)。
- Z 平行性: ハウジング外周を z の上下半分(Δz = 31.5 mm)に分けて円中心を比較して差は 0.00 µm(傾き 0.000 mrad)。円筒の母線は Z に平行。
- 変換後の GLB を再読込して再フィットした結果: 出力軸とリングギアの中心は (-0.0000, -0.0000) mm。

### 座標変換

`平行移動 (m) = (+0.01263236, −0.00364218, −0.03975)`(回転は加えない)。

- X, Y: 回転軸が原点。
- **Z: 出力軸の出力側端面(CAD の z = 39.75 mm)を z = 0 とした**。CAD の元の z から 39.75 mm 引いた値。変換前の Z が必要なときは +39.75 mm。

## 5. 出力寸法(GLB、単位 m、ここでは mm 表記)

全体の bounds: x, y ∈ [-23, 23]、z ∈ [-3, 44]。すなわち **外径 46 mm、軸方向全長 47 mm(ピン先端を含む。筐体のみなら z 0〜44)**。

| ノード | z 範囲 (mm) | 補足 |
|---|---|---|
| output_shaft | 0〜10 | 外径 32 mm の円盤 |
| pin_1〜3 | -3.0〜11.5 | 径 4 mm、長さ 14.5 mm。**出力面(z=0)から -Z 方向へ 3 mm 突出** |
| ring_gear | 0〜12.5 | 外径 46 mm(出力側フランジ、取付穴あり) |
| bearing_main / bearing_center | 1.5〜5.5 / 1.0〜5.0 | |
| housing | 7.0〜42.1 | |
| pcb | 33.7〜40.5 | 43 × 41 mm、中心が軸から -X に 1 mm ずれる(コネクタ部付き?) |
| rear_cover | 39.3〜44.0 | |
| screw_1〜4 | 34〜44 | 長さ 10 mm、頭は z = 44(背面側) |

### ビューア実装者向けの注意

- **出力面は -Z 側**(z = 0、ピン 3 本が 3 mm 突出)。背面(ケーブル側、ねじの頭がある面)は +Z 側(z = 44 mm)。
- 回転は `rotor` ノードを原点まわりに Z 軸で回転するだけでよい(軸が原点・Z なので追加の平行移動不要)。正の回転方向(右手系で +Z まわり)は実機の正方向と**一致**(出力面から見て時計回り。hw_bench.md HW-3、`ROTOR_SIGN = +1`)。
- GLB は位置(POSITION)のみでノーマルを持たない(cascadio が出力しない)。ビューア側で法線を計算する(pyvista は `smooth_shading=True` で可)。色は STEP に無いため仮の PBR 色を付けてある。ビューアで変えてよい。
- GLB の構造: ルート直下に空ノード `stator`、`rotor`。その子が部品ノード(名前は §3 の GLB ノード名)。各メッシュの `extras` に `step_node`(元ノード名)、`name_zh`、`group`。`trimesh.load(..., force="scene", process=False)` で読み込め、親は `scene.graph.transforms.parents[node]` で得られる。pyvista で読む場合は、部品を `rotor` / `stator` ごとに結合し 2 アクタにするのが扱いやすい。
- 出力円盤のオレンジ部(rotor)は回っても円盤が対称なので、回転が分かるのはピン 3 本・円盤上の穴のみ。必要ならビューアで角度目盛りを足すとよい。

## 6. 未確定事項・注意

- `PRT0001` の実体は不明(名前なし)。基板と推定して `pcb` と命名したが、ステータ等の可能性もある。stator 扱いなので動作には影響しない。
- 中心軸受の rotor/stator 帰属は推定(外輪が出力軸の穴に嵌まると判断)。内輪だけが静止側かもしれないが、回転対称なので見た目に影響しない。
- 三角形数は許容差 `0.01 mm / 0.5 rad`(本体)と `1.0 mm / 1.5 rad`(ねじ)で決まる。ねじは頭のヘックス穴が残る程度の粗さで、ねじ山は失われている。
- cascadio は 0.x で API が変わりうる。`tech_stack.md` §5.3 の代替(cadquery-ocp 直接利用)を参照。
